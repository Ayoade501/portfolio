About

From building the web to securing it

My journey in technology began with core software development—mastering HTML, CSS, JavaScript, and Bootstrap to understand how scalable web systems and browser applications function under the hood.

Recognizing that robust code must be secure code, I transitioned my focused trajectory into Application Security (AppSec). Having hands-on software development experience allows me to analyze systems from a developer's perspective while applying proactive security mitigation techniques.

I focus on identifying architectural flaws, mitigating OWASP security risks, performing static/dynamic analysis, and engineering secure web services from concept through deployment.
